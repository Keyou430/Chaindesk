## 执行方式

在 PowerShell 7 中，从工程根目录执行：

```powershell
. ./scripts/chaindesk/bootstrap.ps1 -Install
pnpm.exe install --frozen-lockfile --registry=https://registry.npmjs.org
pnpm.exe chain:verify
pnpm.exe chain:prepare --webview
pnpm.exe chain:smoke
pnpm.exe chain:build-baseline
```

工具链已存在时省略 `-Install`。只准备普通模式开发资源时，省略 `--webview`，避免不必要的完整运行时下载。`chain:build-baseline` 不启动 Vite 开发服务，也不构建 NSIS/MSI 安装包。
